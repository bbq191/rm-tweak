# cang-jie

**[English](docs/README.en.md)**

reMarkable Paper Pro Move 的设备增强套件——**不修改 xochitl（设备官方阅读应用）本体**，通过
xovi 扩展 + 独立 Web 服务，给设备加上书籍管理、笔记增强、系统优化等一整套功能。

## 这是什么

围绕一台墨水屏平板搭的一套个人自用工具：把书弄进设备、按需清洗优化、选去哪个读器（原生
xochitl 或 KOReader）；荧光笔勾画配合手写批注，自动转写成 AI 可处理的笔记，同步进设备笔记本
或 Obsidian；再加上几个底层单点增强（划词精确吸附、手写笔锋渲染、电池诊断、字体/壁纸一键换）。
所有功能都跑在设备的官方系统上，靠 [xovi](https://github.com/asivery/xovi)（第三方扩展加载
框架）+ 一组独立的轻量 Web 服务实现，不侵入、不重打包 `xochitl` 本身。

## 功能一览

六条独立的顶层项目线，各自可插拔、可单独安装：

| 项目 | 是什么 |
|---|---|
| [`shelf/`](shelf/) 书架 | 书籍导入 → 清洗/格式转换/优化 → 落库到原生书库或 KOReader；网页 + host CLI 双入口 |
| [`notes/`](notes/) 笔记线 | 荧光笔勾画 + 旁边手写批注，合书自动摄取 → 手机整理页校对/选 AI 模型转写与问答 → 投影回设备笔记本或 Obsidian |
| [`enhance/`](enhance/) 系统增强 | 荧光笔 CJK 精确吸附、手写笔锋渲染优化（两个独立 xovi 扩展）；电池诊断采样器；字体/壁纸上传即用（两个 Web 服务） |
| [`gateway/`](gateway/) 网关 | 上面三条线共用的唯一 Web 入口：HTTPS（私有 CA）+ 登录密码 + 反向代理到各领域服务 |
| [`rmsvc-core/`](rmsvc-core/) 服务基座 | 各 Web 服务共用的基础设施 crate（路径/注册表/HTTP 适配/事件总线等），不含任何业务逻辑 |
| [`packaging/`](packaging/) 安装器 | 全新设备一条命令装完以上全部（含固件兼容性校验） |

> 各目录内部没有附带单独的说明文档——功能描述都汇总在这份顶层 README 里，直接看代码结构。

## 快速开始

只支持 **reMarkable Paper Pro Move，固件 3.28.0.172**（目前唯一验证过的版本）。

```sh
git clone https://github.com/bbq191/rm-tweak.git
cd rm-tweak/packaging
sh install-all.sh 10.11.99.1
```

完整的前置条件、分步说明、固件安全门、故障排查见 **[INSTALL.md](docs/INSTALL.md)**。

## 历史与范围

这个项目最早从"reMarkable 中文输入法"起步（内部开发代号 `cang-jie` 即"仓颉"，中国传说中造字的
人——本页标题沿用这个名字，但公开发行的这份仓库改叫更贴切的
[`rm-tweak`](https://github.com/bbq191/rm-tweak)），后来陆续长出了阅读增强、PKM 知识管理、
手写识别等更多方向。
2026-09-11 做过一次大规模仓库整理：中文输入法、完整阅读管线、PKM/手写识别这几条较早期的功能线，
连同它们的逆向基座代码，整体移出了内部开发仓库（不是删除，是搬到维护者本机另一个不随 git 走的
目录）——**这些功能目前在设备上仍是现役、仍在正常运行**，只是源码不再随这份公开代码分发，也不再
有活跃开发。当前公开的是上表这六条线，走的是比早期更保守的架构（独立 Web 服务 + 尽量小的 xovi
扩展面），跟设备官方系统的耦合程度比早期低很多。
